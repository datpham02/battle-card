## 4. How to run things

- **Godot 4.6.3** (`godot` on PATH; GDScript). Tests are SceneTree scripts that print `PASS` / `FAIL` and end with
  `FAILS=N`.
- **One test:** `godot --headless --path . -s res://tests/unit/combat/hoa_loi_test.gd`
- **UI tests** (`tests/integration/ui/*`) must run **windowed**:
  `godot --path . --windowed --resolution 1280x720 -s res://tests/integration/ui/<t>.gd -- --no-autopause`
- **Full suite:** `bash tools/qa/run_all_tests.sh <out.txt>`. Last result: **228 / 228 files green in one run**
  (2026-11-09). The output lists `path: FAILS=N k se` (`k se` = script errors).
- After editing `assets/i18n/strings.csv`, reimport with `godot --headless --path . --import` before the card-text
  tests.
- **Battle demo (event log):**
  `godot --headless --path . --fixed-fps 60 --quit-after 400 -- --character=phap_su --seed=1 --match=1 --arena=rect --demo=tram_live --no-autopause --live-card=hoa_loi --tram-shape=bar2 --pattern=wolf --boss-live --cast-when-free`
- **Captures:** run windowed with `--write-movie <dir>/f.png`, then build a contact sheet with
  `godot --headless -s res://tools/qa/compare_sheet.gd -- <out.png> full half <frames> LABEL=<dir>`.
- **Balance probe (complete matches; parallel processes, one per set-up):**
  `godot --headless --path . -s res://tools/balance/hoa_loi_tuning_probe.gd -- --chapters=0,1,2,3,4,5,6,7 --seeds=20 --setups=predict/x2.6 --mults=2.6 --out=<abs>.jsonl`.
  Each process takes about 25 min.

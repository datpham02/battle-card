## What is consistent after this pass

- Run structure, floor assignments and tiers (C1–C3) are stated once in `05` §0 and referenced elsewhere.
- Node vocabulary: `battle, danger, treasure, rest, miniboss, boss, shop, event` (existing) + `forge` (new) in every
  document; slot vocabulary `entry, lane, hub, prepare, gamble, warden`.
- Responsibilities: generator (ids on nodes) → composer (patches/preview) → `RunConfig.from_node(profile)` → combat;
  RunSession owns position, gauge, save; GameFlow orchestrates; views read only.
- Numbers: every tuning value is marked "starting value, gated by `06`"; tier 1 == today everywhere.
- Save: v8, `needs_restart` below 8, both map forms, v1 arena seeds unchanged.
- Validation: baseline first (step 0), BLOCK vs INFO, paired, denominators named, 10k generator seeds.
